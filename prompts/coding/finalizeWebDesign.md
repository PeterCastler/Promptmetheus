## Final visual QA

Before declaring any frontend/UI task complete:

1. Render every affected surface in the actual browser at all required viewport sizes.
2. Visually inspect screenshots—not only DOM, tests, or source code.
3. Check clipping, overflow, masking, safe areas, alignment, typography, spacing, responsive behavior, and interaction states.
4. Treat device frames and presentation chrome as part of the deliverable.
5. Fix every visible defect discovered during this pass, then render and inspect again.
6. Do not declare completion based solely on passing builds, automated checks, or interaction tests.
